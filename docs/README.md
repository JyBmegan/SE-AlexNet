# SE-AlexNet project page

This folder contains the static GitHub Pages site for the SE-AlexNet study. It
uses only release-approved figures and links to the public code and model
repositories.

Primary links:

- Code: https://github.com/JyBmegan/SE-AlexNet
- Model weights and loader: https://huggingface.co/JiayuMBao/SE-AlexNet
- Psychometric fitting: https://github.com/JyBmegan/PsychometricFittingCurve
- Grad-CAM / ROI analysis: https://github.com/JyBmegan/GradCAM-ROI-SaliencyMapDecoder

Manuscript drafts, review correspondence, raw participant data, private
checkpoints, and legacy outputs are not part of the public site.
