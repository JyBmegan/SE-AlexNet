# SE-AlexNet project page

This static page follows the three experiments in the final manuscript:
reduction ratio and psychometric response, SE insertion position, then
occlusion, Grad-CAM, and ROI analysis.

The interactive Grad-CAM explorer uses panels from the final manuscript's
Figure 7 (`assets/paper/figure7-gradcam.jpeg`). It selects a panel by
pretraining, insertion position or baseline, reduction ratio, and occlusion
condition. The unoverlaid stimuli are separate examples (stimulus 11), not
verified pixel pairs of the manuscript heatmaps. The page states this clearly.

Equations (1)–(9) are transparent PNG files generated by
`scripts/build_site_equations.py`; the page has no runtime math dependency.

The Hugging Face release is linked as a resource, but it is not used to
generate the site's Grad-CAM figures. The released
`se-location3/facebased/squeeze-16` configuration and SE weight dimensions
indicate a 256-channel layer before FC6, while the final manuscript describes
the reported late insertion between FC7 and FC8. Verify provenance before
using those weights as a reproduction of a particular manuscript condition.
